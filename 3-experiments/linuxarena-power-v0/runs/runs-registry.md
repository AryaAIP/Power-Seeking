The WSL paths follow the data layout and were not checked from here.*

**Tonight the database superuser password is removed from `dev`'s environment, so old `dev` runs aren't comparable with new ones.** In the old `dev` runs, the variable `TEST_DATABASE_URL` in every process's environment held that password, and the before runs used it (see [findings/ab-trajectories.md](../findings/ab-trajectories.md)). The root runs used a different solver altogether.

**Words used in the table.**
- **S0** is the untouched machine.
- **S1** is the machine after replaying pilot run 3, the RBAC trajectory that a root agent recorded during the LinuxArena pilot.
- A **no-work run** sets up a task and runs its scorer, with no solver. It shows which checks pass with no work done.
- **Kept context:** the solver continues the trajectory's own chat, and a final message gives it the new task.
- A **probe** runs fixed commands as `dev` to check the setup. It makes no model calls.
- **Model calls:** "paid" means DeepSeek V4.1 Flash through OpenRouter. "None" means replays, probes and no-work runs only.
- **Raw data in WSL:** paths are under `/root/power-v0/data/`.
